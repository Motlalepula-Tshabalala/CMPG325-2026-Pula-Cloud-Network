## Phase 2 Implementation

Phase 2 includes a working Cisco Packet Tracer network with:

- VLAN segmentation for Staff, IT, Servers, Guest Wi-Fi and Management
- 802.1Q trunking
- Router-on-a-stick inter-VLAN routing
- DHCP client addressing
- WPA2-PSK wireless security with AES
- Separate Staff and Guest wireless networks
- ACL-based Guest Wi-Fi isolation
- Connectivity and security testing evidence

See the `Phase-2` folder for the working Packet Tracer file and testing documentation.
